Reports <string> entries in strings.xml that are not referenced anywhere in the project as R.string.key (Kotlin / Java) or @string/key (XML).

Example

res/values/strings.xml
    <string name="welcome">Welcome</string>       <!-- used -->
    <string name="legacy_label">Legacy</string>   <!-- flagged: no references -->

Uses a text-based search across the project scope. Dynamic key construction such as getString("legacy_${'$'}suffix") may produce false positives — keys built at runtime are reported as unused.

Toggle in Settings | Tools | StringSmith → Inspection.
