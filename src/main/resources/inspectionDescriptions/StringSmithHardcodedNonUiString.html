Reports hardcoded strings in Kotlin code that is not UI: ViewModels, repositories, utilities, intent extras, preference keys, and technical arguments inside a @Composable such as Modifier.testTag or navigation routes. Offers the same Extract quick-fix as Hardcoded UI string.

Off by default: most of these strings are identifiers that should not be translated. Enable it to audit a module for text that reaches the UI indirectly, for example a message built in a ViewModel and shown later.

What is not reported

  • Strings reported by Hardcoded UI string
  • Tests, generated code under build/, Gradle scripts, buildSrc / build-logic, benchmark and baseline-profile modules
  • const val, annotation arguments, exception messages, logging calls, previews
  • Strings without letters, strings shorter than the minimum length or matching an exclusion pattern, and string templates outside Compose and Android classes
