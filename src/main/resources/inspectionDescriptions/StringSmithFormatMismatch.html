Reports a <string> in a locale file (values-*/strings.xml) whose format specifiers (%s, %d, %1$s, …) do not match the default values/strings.xml entry for the same key.

A dropped, added, or retyped argument crashes at runtime with IllegalFormatException as soon as that locale is shown.

Example

<!-- values/strings.xml -->
<string name="greeting">Hello %1$s, you have %2$d messages</string>

<!-- values-de/strings.xml -->
<string name="greeting">Hallo %1$s</string>        <!-- flagged: 2 args expected, 1 here -->
<string name="greeting">Hallo %1$s, %2$s Nachrichten</string>  <!-- flagged: arg 2 is %d, not %s -->

Works for both Android res/values* and Compose Multiplatform composeResources/values* layouts. For Compose Multiplatform, Android Lint provides no equivalent check.

%% is treated as an escaped percent and %n as a no-argument line separator, so ordinary text such as 50% off is never flagged.

Toggle in Settings | Tools | StringSmith → Inspection.
