Reports two or more <string> entries in the same strings.xml file that share the same text content but use different keys.

Encourages key reuse so translators do not translate the same sentence twice and the app stays consistent.

Example

<string name="login_title">Welcome</string>
<string name="onboarding_greeting">Welcome</string>  <!-- flagged -->

Comparison is exact-match on the trimmed text. Entries with translatable="false" are still considered.

Toggle in Settings | Tools | StringSmith → Inspection.
