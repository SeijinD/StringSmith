Extracts a hardcoded string literal into the Android strings.xml resource file.

Available on:

  • Kotlin String literals inside @Composable, Activity, Fragment, generic Kotlin, etc.
  • XML layout attribute values

The replacement adapts to the context:

  • @Composable → stringResource(R.string.key)
  • Activity / Fragment → getString(R.string.key)
  • Other Kotlin → R.string.key
  • XML layout → @string/key

Imports for stringResource and the project's R class are added automatically.
