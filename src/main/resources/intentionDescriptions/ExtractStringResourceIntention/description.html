Moves a hardcoded string into res/values/strings.xml and replaces the literal with a context-appropriate reference. Imports added automatically.

ContextReplacement
@ComposablestringResource(R.string.key)
Activity / FragmentgetString(R.string.key)
Other KotlinR.string.key
XML layout@string/key

Before

Text("Hello, world!")

After

Text(stringResource(R.string.hello_world))

Templates with $-expressions become format arguments ("Hi $name" → Hi %1$s plus name as an argument) in @Composable and Activity / Fragment code, when Detect format args is on. Elsewhere they are skipped.

Skips: short literals, exclusion regexes, @Preview composables, XML refs starting with @ / ?.
