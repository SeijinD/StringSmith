Copies the string resource referenced under the caret to a new key, writing the same value into res/values/strings.xml and every matching values-* locale file in one undoable step.

Works on any reference to a string resource:

ReferenceSystem
R.string.keyAndroid
Res.string.keyCompose Multiplatform
@string/keyAndroid XML
<string name="key">strings.xml entry

Before

Text(stringResource(R.string.hello_world))

After

Text(stringResource(R.string.hello_world_copy))

Pick the new key in the dialog. Optionally redirect the reference under the caret to the new key (imports are updated for Compose Multiplatform). Locales that already contain the new key are left untouched.

Configure strings.xml sort and open-after behavior in Settings | Tools | StringSmith.
