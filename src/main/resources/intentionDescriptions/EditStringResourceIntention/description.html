Edits the string resource referenced under the caret: rename its key and change the default and per-locale values in one undoable step. Renaming the key updates every R.string/Res.string/@string/ reference across the declaring module and its dependents.

Works on any reference to a string resource:

ReferenceSystem
R.string.keyAndroid
Res.string.keyCompose Multiplatform
@string/keyAndroid XML
<string name="key">strings.xml entry

Before

Text(stringResource(R.string.hello_world))

After

Text(stringResource(R.string.welcome_message))

Change the key and/or the default and per-locale values in the dialog. On rename, the dialog reports how many references were updated, and warns when none were found (e.g. a dynamically built key).

Configure strings.xml sort and open-after behavior in Settings | Tools | StringSmith.
